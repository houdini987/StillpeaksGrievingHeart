# Stillpeak’s Grieving Heart — Canon Layer

## Authority Rule

This repository is now the authoritative source of truth for Stillpeak’s Grieving Heart canon.

### Canonical Files

- Files ending in `.canon.md` are the live canonical source for scene packets.
- Files under `canon/appendices/` are live supporting canon unless explicitly marked otherwise.
- Files under `assets/images/` are the canonical visual asset layer once linked.
- Exported `.docx` and `.pdf` artifacts are derived outputs, not source canon.

## DM Project Consumption Guidance

This repo is intended to support a separate DM-facing project used during live gameplay.

The DM project should consume this repo using these rules:

- Treat `.canon.md` packet files as the authoritative narrative and mechanics source.
- Preserve exact rules language where canon defines DCs, encounter logic, conditions, item behavior, or progression rules.
- Do not summarize away systemic truths such as:
  - Tremorscope behavior
  - Karagvorn Line reinterpretation of rules
  - encumbrance pressure
  - grief-field logic
- Live gameplay state such as HP, initiative, temporary conditions, resource depletion, inventory drift, or token state belongs to Roll20/live state unless intentionally promoted back into this repo.
- Session outcomes may inform future canon revisions, but they should not overwrite packet canon casually.

## Future Packet Structure Rule

All future scene packets should follow this exact section order:

1. At-a-Glance Summary
2. Narrative Setup (Canonical Text)
3. Read-Aloud Scene Introduction
4. Environment Overview
5. Running the Location
6. Encounter Modules
7. Player Curiosity Hooks
8. Escalation Signal
9. Rewards / Discoveries
10. DM Reference Sidebar
11. Map Reference

## Authoring Standards

- Preserve restrained tone; avoid melodramatic escalation.
- Keep environmental pressure primary; creatures are often expressions of the mountain’s condition, not the main point.
- Preserve the Tremorscope as the most reliable directional truth source.
- Treat the Karagvorn Line as reinterpretation of rules, not blanket suppression of magic.
- Keep checks, DCs, and rewards explicit.
- Prefer modular, segment-based design as danger escalates.
- Avoid duplicate canon layers; revise the existing `.canon.md` file rather than creating parallel alternates.
