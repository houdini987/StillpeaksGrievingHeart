# Session Logs

This folder records what actually happened at the table during live play of **Stillpeak's Grieving Heart**.

## Purpose

These files are intended to help the live DM support project and the separate ideation/design project communicate cleanly.

- Canon scene packets remain the authoritative design source.
- Session logs record actual table outcomes, player choices, rulings, deviations, discoveries, and pause points.
- Session logs may inform future prep, continuity, and recap work, but they do not override canon unless a later canon file or explicit project instruction promotes a detail.

## Usage Guidance

When starting a new live session, read the most recent session log first, then read the relevant canon packet(s).

When doing ideation or future packet design, treat these logs as actual-play context and continuity history rather than as canonical module text.
