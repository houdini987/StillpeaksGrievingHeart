# Stillpeak's Grieving Heart

A homebrew D&D 5e campaign set in the eastern Spine of the World: a bleak survival climb up a mountain whose grief has become geological, followed by a descent into the dwarven kingdom sealed inside it.

Designed with ChatGPT (2025–2026) and continued with Claude Code.

## Where to start

- **Campaign overview and story spine:** `canon/START_HERE.md`
- **Every canon file, by packet:** `canon/CANON_MANIFEST.md`
- **Where the party is right now:** `bootstrap/SESSION_STATE.md`
- **What happened at the table:** `session-logs/` (latest via `session-logs/LATEST_SESSION_LOG.md`)
- **AI operating rules:** `bootstrap/BOOTSTRAP.md`

## Working with Claude Code

Open this folder in Claude Code. `CLAUDE.md` loads automatically, and two project skills are available:

- `/dm`: live-table runtime (`OPEN SESSION`, `BEAT`, `NPC`, `RULING`, `CHECKS`, `TRANSITION`, `RECAP`, `PAUSE POINT`, `CLOSE SESSION`)
- `/ideate`: canon design and prep, resuming from the active packet handoff

Maps, art, and character sheets are kept outside the repo; see `assets/ASSET_INDEX.md`.
